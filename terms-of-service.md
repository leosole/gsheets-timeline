## 1. Description of the Service

gsheets-timeline is a Google Sheets modal extension that reads data from the active spreadsheet and renders it as a visual project timeline. The Add-on allows you to:

- Configure which spreadsheet columns are used for task names, start dates, end dates, due dates, and metadata
- View a generated timeline based on the data in your active sheet
- Refresh the timeline to reflect the latest data in your spreadsheet
- View additional task metadata through popup fields

The Add-on runs inside your own Google Sheets environment via Google Apps Script and displays the timeline within a modal. It does not modify the underlying spreadsheet data.
